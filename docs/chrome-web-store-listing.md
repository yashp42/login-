## KGP ERP One-Click Login

Chrome extension for locally stored IIT Kharagpur ERP credential autofill.

The current release fills a saved roll number, password, and security-question answer on the ERP login page. It has no backend and no analytics. Gmail OTP support is not available until the later Gmail integration phase.

Source code: https://github.com/yashp42/login
